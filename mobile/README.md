# تطبيق باقات للجوال

تطبيق أصلي مبني باستخدام React Native وExpo لنظامي Android وiOS. يقرأ الباقات من خدمة باقات المنشورة ويستخدم مشروع Firebase نفسه لحسابات العملاء والتجار. يحتفظ بجلسة الدخول والرموز في الذاكرة خلال تشغيل التطبيق.

## المعاينة

```sh
npm ci
npx expo start
```

افتح التطبيق بواسطة Expo Go إذا كان الإصدار المثبت يدعم إصدار المشروع. يُنشئ سير عمل **Baqat Android preview** في GitHub حزمة APK موقعة بمفتاح التطوير للاختبار الداخلي. لتنزيلها افتح تشغيلًا ناجحًا من تبويب **Actions** ثم نزّل `baqat-android-preview-apk` من **Artifacts**.

بناء Android أو iOS من Expo يتطلب ربط المشروع بحساب Expo. لإصدار iOS القابل للتوزيع، استخدم أيضًا حساب Apple Developer والتوقيع ومعرّف التطبيق الموافق له. ملفات الإعداد تضبط معرّفًا مبدئيًا هو `com.alvra.baqat` على النظامين. تحقق من توفره وملكيته قبل أول توزيع.

## الدخول بالجوال

سجّل تطبيق iOS وتطبيق Android داخل مشروع Firebase الحالي، بالمعرّف `com.alvra.baqat` على النظامين. أضف ملفي إعداد التطبيق الأصليين في هذا المجلد للتطوير المحلي، أو عرّفهما كمتغيرات ملفات في Expo باسم `GOOGLE_SERVICE_INFO_PLIST` و`GOOGLE_SERVICES_JSON`. عند غياب إعداد التطبيق الأصلي يبقى الدخول بالبريد متاحًا.

فعّل طريقة Phone في Firebase واسمح بالسعودية في سياسة مناطق الرسائل. أضف بصمتي SHA-1 وSHA-256 لتوقيع Android. هيّئ APNs ومعرّف إعادة التوجيه المطلوب في iOS. اختبر الأرقام الوهمية المخصصة للاختبار أولًا. إرسال رسائل فعلية يتطلب إعداد فوترة Firebase. اختبر البناء الأصلي على جهازين قبل التوزيع.

صاحب الحساب الحالي يدخل بالبريد، ثم يختار «اربط رقم جوالك بحسابك» ويؤكد البريد الحالي ورقم الجوال. الربط يحفظ معرف المستخدم، فيبقي الطلبات والباقات والصلاحيات على الحساب نفسه. اعتماد المنشآت عبر لوحة إدارة الويب باستخدام حسابات Firebase المخولة.
