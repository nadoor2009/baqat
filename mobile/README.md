# تطبيق باقات للجوال

تطبيق أصلي مبني باستخدام React Native وExpo لنظامي Android وiOS. يقرأ الباقات من خدمة باقات المنشورة ويستخدم مشروع Firebase نفسه لحسابات العملاء والتجار. يحتفظ بجلسة الدخول والرموز في الذاكرة خلال تشغيل التطبيق.

## المعاينة

```sh
npm ci
npx expo start
```

افتح التطبيق بواسطة Expo Go إذا كان الإصدار المثبت يدعم إصدار المشروع. يُنشئ سير عمل **Baqat Android preview** في GitHub حزمة APK موقعة بمفتاح التطوير للاختبار الداخلي. لتنزيلها افتح تشغيلًا ناجحًا من تبويب **Actions** ثم نزّل `baqat-android-preview-apk` من **Artifacts**.

بناء Android أو iOS من Expo يتطلب ربط المشروع بحساب Expo. لإصدار iOS القابل للتوزيع، استخدم أيضًا حساب Apple Developer والتوقيع ومعرّف التطبيق الموافق له. ملفات الإعداد تضبط معرّفًا مبدئيًا هو `com.alvra.baqat` على النظامين. تحقق من توفره وملكيته قبل أول توزيع.
