# باقات الرياض

واجهة عربية للبحث عن باقات المطاعم ومقارنتها. يضيف التاجر المعتمد الأسعار والمكونات وفترات التوفر وإحداثيات الفرع. تتولى قاعدة Cloudflare D1 حفظ البيانات، ويشغّل Cloudflare Worker الواجهة وواجهة البرمجة، ويدير Firebase Authentication حسابات العملاء والتجار.

## التجربة المحلية

يتطلب المشروع Node.js وأداة Wrangler. تعمل قراءة الباقات محليًا دون إعداد Firebase. لتجربة الحسابات استخدم مشروع Firebase مخصصًا لباقات، وفعّل البريد الإلكتروني وكلمة المرور، يقرأ التطبيق مفتاح الويب العام من `FIREBASE_API_KEY` في `wrangler.toml`. لتجربة مشروع مختلف محليًا، اضبط نفس الاسم في ملف `.dev.vars`.

```sh
npx wrangler d1 migrations apply DB --local
npx wrangler dev
```

## النشر

1. سجل الدخول إلى حساب Cloudflare وتحقق من ارتباط قاعدة D1 المسماة `baqat-riyadh` بالمتغير `DB` في Worker الإنتاج.
2. في قاعدة جديدة، طبّق الترحيلات وانشر التطبيق. قاعدة باقات الحالية هُيئت من لوحة Cloudflare بملف `0001_baqat.sql`. تحقق من سجل التهيئة قبل تطبيق الترحيل عليها مجددًا. مفتاح Firebase هنا مخصص لتطبيق الويب ويظهر من `/api/config`. تُدار قيود واجهات Google المسموحة من Google Cloud Console. يحتاج تسجيل الدخول والتجديد إلى Identity Toolkit API وSecure Token API. اختبر أي قيد مرجعي على الويب والجوال قبل اعتماده.
3. جرّب تأكيد البريد وتسجيل الدخول باستخدام حسابين مستقلين، ثم اختبر النشر والرمز من جهة العميل والتاجر.

```sh
npx wrangler login
npx wrangler d1 migrations apply DB --remote
npx wrangler deploy
```

## حساب التاجر والرموز

يؤكد التاجر بريده ويطلب الاعتماد من «حسابي». تظهر لوحة «اعتماد التجار» للمسؤول بعد تسجيل الدخول عبر الويب. فعّلها في إعدادات Worker بإضافة المتغير `BAQAT_ADMIN_UIDS` بقيم معرّفات Firebase للحسابات الإدارية المؤكّدة، مفصولة بفواصل. استخدم معرّفات الحسابات من Firebase Authentication، وراجع هوية المنشأة قبل اعتمادها. يستطيع التاجر بعدها حفظ مسودة ونشر باقته.

يحفظ الخادم بصمة الرمز، ويربط صلاحية استخدامه بالتاجر صاحب الباقة. ينتهي الرمز بعد ٣٠ دقيقة أو بانتهاء الباقة، أيهما أسبق، ويمكن استعماله مرة واحدة. يوجد حد عشرة رموز لكل حساب في الساعة، ورمز نشط واحد لكل عميل وباقة. تبقى جلسة حساب العميل والرمز الصريح في ذاكرة الصفحة حتى تحديثها أو تسجيل الخروج. يُجدّد رمز الهوية عند اقتراب انتهائه أثناء استخدام التطبيق. يدفع العميل لدى المنشأة إن كان العرض مدفوعًا.
