# باقات الرياض

واجهة عربية للبحث عن باقات المطاعم ومقارنتها. يضيف التاجر المعتمد الأسعار والمكونات وفترات التوفر وإحداثيات الفرع. تتولى قاعدة Cloudflare D1 حفظ البيانات، ويشغّل Cloudflare Worker الواجهة وواجهة البرمجة، ويدير Firebase Authentication حسابات العملاء والتجار.

## التجربة المحلية

يتطلب المشروع Node.js وأداة Wrangler. تعمل قراءة الباقات محليًا دون إعداد Firebase. لتجربة الحسابات استخدم مشروع Firebase مخصصًا لباقات، وفعّل البريد الإلكتروني وكلمة المرور، ثم ضع مفتاح تطبيق الويب العام في ملف `.dev.vars` المحلي تحت اسم `FIREBASE_API_KEY`.

```sh
npx wrangler d1 migrations apply DB --local
npx wrangler dev
```

## النشر

1. سجل الدخول إلى حساب Cloudflare، ثم أنشئ قاعدة D1 باسم `baqat-riyadh`. استبدل المعرف الصفري في `wrangler.toml` بمعرف القاعدة.
2. طبّق ترحيل قاعدة البيانات وانشر التطبيق، ثم اربط مفتاح تطبيق Firebase العام. لا ترفع مفاتيح حسابات الخدمة أو رموز الوصول.
3. جرّب تأكيد البريد وتسجيل الدخول باستخدام حسابين مستقلين، ثم اختبر النشر والرمز من جهة العميل والتاجر.

```sh
npx wrangler login
npx wrangler d1 create baqat-riyadh
npx wrangler d1 migrations apply DB --remote
npx wrangler deploy
npx wrangler secret put FIREBASE_API_KEY
```

## حساب التاجر والرموز

يؤكد التاجر بريده ويطلب الاعتماد من «حسابي». بعد مراجعة المنشأة، يعتمد مسؤول المنصة معرف مستخدم Firebase المطابق لطلب التاجر من قاعدة البيانات، بضبط حقل `approved` على `1` في جدول `merchants`. يستطيع التاجر بعدها حفظ مسودة ونشر باقته.

يحفظ الخادم بصمة الرمز، ويربط صلاحية استخدامه بالتاجر صاحب الباقة. ينتهي الرمز بعد ٣٠ دقيقة أو بانتهاء الباقة، أيهما أسبق، ويمكن استعماله مرة واحدة. يوجد حد عشرة رموز لكل حساب في الساعة، ورمز نشط واحد لكل عميل وباقة. تبقى جلسة حساب العميل والرمز الصريح في ذاكرة الصفحة حتى تحديثها أو تسجيل الخروج. يدفع العميل لدى المنشأة إن كان العرض مدفوعًا.
